# Photos

Optional portrait images for the family tree cards. A card without a photo shows the person's initials.

To add one:

1. Put the image here, e.g. `photos/joen-miraflores.jpg` (square, about 200x200 px, under 50 KB).
2. In `data/families.js`, add `"photo": "photos/joen-miraflores.jpg"` to that person's entry.

Only use images you have the right to publish, such as official portraits whose terms allow reuse, or photos you took yourself. Record where each image came from below.
